## Étapes CI

Orchestrateur : GitHub Actions. Image publiée : `$AWS_ACCOUNT_ID.dkr.ecr.eu-west-3.amazonaws.com/mon-app:<commit>`.

1. Tests unitaires
2. Qualité SonarQube
3. Build et publication de l'image (BuildKit (docker buildx))
4. Plan OpenTofu
5. Application OpenTofu (branche principale, manuel)
6. Déploiement ECS — Préproduction (branche principale)
7. Déploiement ECS — Production (branche principale, manuel)

Les variables sans valeur sont à déclarer dans la CI ; les autres sont déjà écrites dans les fichiers.

| Variable | Secret | Valeur | Rôle |
