## Étapes CI

Orchestrateur : Azure Pipelines. Image publiée : `europe-west9-docker.pkg.dev/mon-projet/mon-app/mon-app:<commit>`.

1. Tests unitaires
2. Qualité SonarQube
3. Recherche de secrets
4. Build et publication de l'image (BuildKit (docker buildx))
5. Scan de vulnérabilités Trivy
6. Signature de l'image (Cosign) (branche principale)
7. Plan Terraform
8. Application Terraform (branche principale, manuel)
9. Déploiement Cloud Run — Développement (branche principale)
10. Déploiement Cloud Run — Préproduction (branche principale)
11. Déploiement Cloud Run — Production (branche principale, manuel)
